# Apps

The apps are complete applications built with the HTTP inbox and the state machine. Both are compiled with GraalVM to
native executables, packaged in container images built from `scratch`, and run on SQL Server with Docker Compose.

| App                                       | Module                   | What it does                                                                                                    |
|-------------------------------------------|--------------------------|-----------------------------------------------------------------------------------------------------------------|
| [Identity provider](identity-provider.md) | `apps/identity-provider` | An OAuth 2.0 authorization server for the client credentials grant, and an OpenID Connect provider for web apps |
| [Hello world demo](hello-world.md)        | `apps/hello-world`       | A hello world web application following the principles of the twelve-factor app                                 |

Both can be [deployed to Azure Functions](azure-functions.md) with a serverless Azure SQL database by the `deploy`
module, as can any other application built the same way.

See the [architecture](architecture.md) for the parts the apps are built from.

## Documenting an app

The page of each app has the same sections, in this order, so that the model comes first and what is particular to the
app comes after what all apps have:

1. **Model.** A table of the app's entity models, the state diagram of each and an ER diagram of the whole model. The
   diagrams are generated by the `doc-diagrams` module (see [Diagrams](diagrams.md)), which a new app is added to.
2. **Endpoints.** The HTTP requests the app serves.
3. What is particular to the app, such as the [credentials](identity-provider.md#credentials) of the identity provider
   or the [twelve factors](hello-world.md#the-twelve-factors) of the demo.
4. **Running.** How to run it with Docker Compose and build its image, with its **Configuration**.
5. **Gaps.** What the app or the libraries lack.
